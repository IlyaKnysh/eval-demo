# Evaluating the automation-framework-review skills

This repo has three parallel implementations of the same skill — review a test
automation framework and produce an evidence-cited issues list — each paired
with its own evaluation harness:

| Skill directory | Eval approach | Run with |
|---|---|---|
| `.claude/skills/automation-framework-review-deepeval/` | DeepEval (pytest + LLM-judge + deterministic checks) | `pytest` |
| `.claude/skills/automation-framework-review-eval-plugin/` | `claude plugin eval` (YAML cases, markdown graders) | `bash run-evals.sh` |
| `.claude/skills/automation-framework-review-skill-creator/` | skill-creator's native flow (subagents + HTML benchmark viewer) | manual, inside a Claude Code session |

---

## 1. DeepEval suite (pytest)

**What it does:** grades review documents in `evals/outputs/<scenario>.md`
against each fixture's seeded-defect manifest, using a mix of an LLM-judge
(GEval) and plain deterministic string/structure checks. There's no live app
entry point to invoke the skill during `deepeval test run`, so a missing
review is auto-generated by a pytest hook before grading — see below.

### One-time setup

```bash
cd .claude/skills/automation-framework-review-deepeval
pip install deepeval pytest
```

The judge model shells out to the `claude` CLI per metric call, so the
`claude` CLI must be on `PATH` and authenticated.

### Run the suite

```bash
cd .claude/skills/automation-framework-review-deepeval
pytest
```

Reviews already exist for all three fixtures at
`evals/outputs/{clean,medium,messy}-framework.md`, so this will grade those
as-is. If an output file is missing or blank, `conftest.py` auto-generates it
first (before any test runs).

---

## 2. claude plugin eval (YAML + markdown graders)

**What it does:** runs the skill live inside a sandboxed Claude Code
invocation per case (currently one: `01-ui-messy-full-review`), using a
`scaffold.sh` to populate the sandbox with the fixture repo, then grades the
output with a set of markdown-described graders (one per expected
defect/behavior).

### Run it

```bash
cd .claude/skills/automation-framework-review-eval-plugin
run-evals.sh
```

---

## 3. skill-creator native flow (subagents + HTML viewer)

### Run it

Call the `skill-creator` skill and ask it to make/run an evaluation for the
`automation-framework-review-skill-creator` skill.
